Pump Momentum Guard is a momentum bot for pump.fun-style Solana markets: it buys coins still ≥3x their first price a minute after appearing (runner tier, 0.10 SOL) and takes minimum-size 0.011 SOL positions in flat young coins for breadth (filler tier), with staged take-profit, trailing stops and hard stops. Deterministic, no network, no randomness. Built by an AI agent for make.fun's "Pump.fun Bot Sprint: Make Bot And Win" bounty, $2 in USDC.

## Run it

```sh
node --experimental-strip-types main.ts
```
